# Py-Scripts_for_Functions_Modules_Library
Scripts include: A simple tic-tac-toe game and A data Visualisation task Using Matplotlip.                                                                                                                                                                  
---For the Tic-Tac-Toe game built in Python, it features
- A human player (`X`)
- An AI opponent agent (`O`) with a basic win/block strategy
This project is beginner-friendly and demonstrates:
- Game loop logic
- Win/tie detection
- Basic AI decision-making
- Clean, readable Python code

How to Play
The board is labeled either by numbers (0–8) or coordinates (A1, B2, etc.) depending on the version.
Enter your move when prompted.
The AI will respond immediately after your turn.
The game ends when:
You win 
You Lose (The AI wins) 
It's a tie

The dataset contains:

Month number
